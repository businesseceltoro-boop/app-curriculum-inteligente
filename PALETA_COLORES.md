## 6. DIRECTRICES DE APLICACIÓN

### En la Web Principal
- Fondo: Blanco (#FFFFFF)
- Navegación: Azul (#0052CC)
- CTAs principales: Verde (#10B981)

- El usuario selecciona sector/puesto
- Sistema aplica automáticamente paleta

- Vista previa en tiempo real

- Premium: Dorado (#D97706)
